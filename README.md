# Notion Editor CZ

Nový dark-first blokový editor pro desktop, tablet a iPhone.

## Hlavní funkce

- Tiptap editor
- blokové ovládání v levém gutteru
- vlastní nabídka pravého kliku
- české UI
- dark-first design
- `/` workflow připravené pro command vrstvu
- `Ctrl/Cmd + K` Web Search
- serverová web-search route
- responsive mobilní režim
- GitHub Actions CI
- Vercel-ready Next.js App Router

## Lokální vývoj

```bash
pnpm install
pnpm dev
```

## Kontrola

```bash
pnpm lint
pnpm typecheck
pnpm build
```

## Vercel

Projekt je připraven pro napojení na Vercel a automatické Preview/Production deploymenty přes GitHub.
